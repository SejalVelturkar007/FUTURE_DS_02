# FUTURE_DS_02

## Customer Retention & Churn Analysis

This project is completed as part of the Future Interns Data Science & Analytics Internship – Task 2.

### Project Objective
The objective is to analyze customer churn patterns, retention drivers, and customer lifetime trends for a subscription-based business.

### Tools Used
- Power BI
- DAX
- GitHub

### Analysis Covered
- Overall churn rate
- Churned customers
- Churn by subscription type
- Churn by contract length
- Churn by support calls
- Churn by payment delay
- Churn by tenure
- Churn by usage frequency
- Customer lifetime trend using total spend and tenure
- Churn by gender and age
- Tenure-based cohort analysis

### Key Insights
- Overall churn rate is 56.71%.
- 249,999 customers are identified as churned.
- Monthly contract customers show higher churn compared with longer-term contracts.
- Higher support calls are associated with higher churn.
- Payment delays show an increasing churn pattern.
- Premium customers show slightly higher churn than Standard and Basic customers.
- Churn is relatively similar across gender and different tenure/usage groups.

### Recommendations
- Encourage monthly customers to move to longer-term contracts.
- Proactively support customers with frequent support calls.
- Reduce payment delays through reminders and easier payment options.
- Review Premium customer benefits and value.
- Identify high-risk customers using tenure, usage and spending patterns.
- Run targeted retention campaigns and loyalty offers.

### Deliverable
Power BI dashboard for Customer Retention & Churn Analysis.
